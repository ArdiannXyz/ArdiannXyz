### 👨‍💻 About Me

Halo! Saya **Ardian**, seorang mahasiswa Teknologi Informasi di **Politeknik Negeri Jember** yang berfokus pada **Full-Stack Web Development** dan **Cross-Platform Mobile Apps**. Saya memiliki antusiasme tinggi dalam membangun solusi perangkat lunak yang andal, scalable, dan berorientasi pada kenyamanan pengguna.

- 🔭 **Keahlian Utama:** Arsitektur backend dengan **Laravel**, desain database relasional **MySQL**, pengembangan RESTful API, dan aplikasi mobile modern berbasis **Flutter**.
- 📱 **Mobile Development:** Berpengalaman merancang antarmuka mobile yang responsif, state management yang rapi, dan integrasi backend secara real-time.
- 🐳 **DevOps & Cloud Explorer:** Aktif mempelajari containerization dengan **Docker**, deployment orkestrasi via **Kubernetes (Minikube)**, serta pipeline CI/CD.
- 💡 **Filosofi Belajar:** Konsisten mengasah keterampilan problem-solving dan menulis kode yang bersih (*clean code*) sesuai standar industri.
- 💬 **Diskusi & Tanya Saya:** Web development (Laravel/PHP), Flutter/Dart, Database Modeling, REST API, atau proyek kolaborasi.
- 📫 **Hubungi Saya:** [kaptenstayy@gmail.com](mailto:kaptenstayy@gmail.com)
